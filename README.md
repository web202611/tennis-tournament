# 网球比赛管理系统

纯前端网球赛程管理系统，双击 `index.html` 即可使用（数据保存在浏览器 `localStorage`）。

赛制严格按需求实现：**4 个小组 × 4 队单循环 → 每组前 2 名（8 队）→ 1/4 决赛 → 半决赛 → 季军赛 / 决赛**。

## 一、功能

### 比赛类别
默认内置 5 个类别，可继续自定义新增/删除：

| 类别 | 类型 | 每队人数 |
| --- | --- | --- |
| 男子单打 | 单打 | 1 |
| 女子单打 | 单打 | 1 |
| 男子双打 | 双打 | 2 |
| 女子双打 | 双打 | 2 |
| 混合双打 | 双打 | 2 |

每个类别独立维护报名、分组、赛程与淘汰赛数据，通过右上角下拉框切换。

### 赛事管理与历史归档
- **比赛时间标识**：每场赛事带比赛日期，可在「赛事管理」中修改；小组赛页、淘汰赛页、冠军横幅均显示该时间
- **新建赛事（归档当前）**：比赛全部结束后点击，当前赛事自动归档并保留全部数据（报名、赛程、冠军），同时开启一场空的新赛事
- **历史赛事页（第 4 个 Tab）**：完整回放每一届比赛的全过程
  - 顶部「选择赛事」列出当前类别下所有有比赛数据的赛事（含进行中与已归档），显示日期、状态与冠军，点击即可切换
  - 最终名次：冠军 / 亚军 / 季军 + 比赛时间
  - 小组赛全程：A/B/C/D 四组每一轮每一场的比分 + 完整积分榜
  - 淘汰赛全程：1/4 决赛、半决赛、季军赛、决赛每一场比分与最终冠军
  - 只读展示，比分不可编辑；无数据时给出明确提示
- **历史赛事下拉**：在「报名分组 → 赛事管理」中选择往届赛事会**自动跳转历史详情页**
- **删除赛事**：可删除不需要的赛事（至少保留一个）
- 旧版本数据打开时自动迁移为带比赛时间的赛事结构，不丢失任何数据

### 报名
- 录入参赛人员姓名：单打 1 人，双打 2 人（自动组成一队，显示为「甲 / 乙」）
- 自动去重、最多 16 队、比赛开始后禁止增删队伍

### 分组抽签
- 报满 16 队后可「随机抽签」，随机分为 A/B/C/D 四组，每组 4 队
- 小组赛开赛前可重新抽签（会清空赛程）
- 「生成小组赛程」自动生成每组 6 场、共 24 场单循环对阵（3 轮）

### 小组赛
- 每组展示 3 轮 6 场比赛，点击比分框录入比分
- 实时积分榜：胜场 → 净胜分 → 总得分排序，前 2 名高亮标记
- 全部 24 场完成后可「生成淘汰赛对阵」

### 淘汰赛
- 八强对阵规则：
  - 上半区：A1 vs B2，C1 vs D2
  - 下半区：B1 vs A2，D1 vs C2
- 半决赛：1/4 决赛 1 胜者 vs 2 胜者；3 胜者 vs 4 胜者
- **半决赛负者进入季军赛**，胜者进入决赛
- 比分录入后自动晋级，冠军/亚军/季军实时展示
- 修改上游比分时，依赖其结果的后续比赛比分自动失效，避免数据不一致
- 支持「重新生成对阵」（按当前小组排名重建，清空淘汰赛比分）

### 比分规则
- 双方比分需为非负整数且不能相同，高者获胜
- 可按局数、盘数或总分录入（系统只比较大小）

## 二、赛制说明

```
16 队报名
   ↓ 随机抽签
A组(4队)  B组(4队)  C组(4队)  D组(4队)
   ↓ 组内单循环（每组 6 场，共 24 场）
每组前 2 名晋级 → 8 队
   ↓
1/4 决赛（4 场）
   ↓
半决赛（2 场）—— 负者 → 季军赛
   ↓
决赛（1 场） → 冠军
```

## 三、快速开始

1. 双击打开 `index.html`
2. 在「比赛类别」中选择类别（如男子单打）
3. 在「参赛报名」录入 16 名/队选手姓名
4. 点击「随机抽签」→「生成小组赛程」
5. 在「小组赛」逐场点击比分框录入结果
6. 全部完成后点击「生成淘汰赛对阵」
7. 在「淘汰赛」录入 1/4 决赛、半决赛、季军赛、决赛比分，冠军自动产生

> 想快速预览效果：点击「一键演示数据」，系统会自动生成 16 队、完成抽签、模拟全部小组赛与淘汰赛，并跳转到淘汰赛页展示冠军。

## 四、文件结构

```
tennis-tournament/
├── index.html   # 页面结构（报名分组 / 小组赛 / 淘汰赛 + 比分弹窗）
├── styles.css   # 蓝白简约风格、对阵图布局
├── app.js       # 赛制核心算法 + 数据存储 + 交互渲染
└── README.md
```

### 核心算法（`app.js` 中的 `Core`）
- `Core.pairs(teamIds)`：圆桌轮转法生成单循环赛程（4 队 → 3 轮 6 场）
- `Core.rankGroup(teamIds, matches)`：小组积分排名（胜场 / 净胜分 / 总得分）
- `Core.buildKo(standings)`：由小组排名生成八强对阵树
- `Core.resolveSide(side, ko)`：递归解析对阵席位（队伍 / 胜者 / 负者）

## 五、数据存储

- 存储键：`tennis_tournament_v1`
- 结构：`{ cats, activeId, seq, data: { [类别ID]: { teams, groups, gm, ko } } }`
- 清除数据：浏览器控制台执行 `localStorage.removeItem('tennis_tournament_v1')` 后刷新

## 六、注意事项

- 小组赛采用**单循环**（每两队交手一次），4 队共 3 轮 6 场
- 每类别最多 16 队，需报满 16 队才能抽签（保证 4 组 × 4 队）
- 平局不被允许（网球比赛无平局）
- 小组赛排名若胜场相同，依次比较净胜分、总得分
